# Global Food & Plastic Waste Analytics

## Project Overview
This project analyzes global UN environmental datasets from 2010 to 2019 to investigate trends in food waste and mismanaged plastic waste. It focuses on rigorous data preparation and statistical modeling to uncover correlations and key environmental insights.

## Tools & Technologies
* **Analytical Software:** SAS
* **Techniques Used:** Iterative Data Cleaning, Complete-Case Filtering, Data Validation, Correlation & Regression Analysis

## Methodology
1. **Data Cleaning & Validation:** Processed raw environmental datasets using iterative cleaning and Complete-Case Filtering protocols to handle missing values and ensure data integrity.
2. **Correlation Analysis:** Evaluated the statistical relationships between food waste volumes and plastic mismanagement metrics across different regions.
3. **Regression Modeling:** Utilized regression analysis to model waste trends and identify significant predictors over the decade.
